## 1. Overview & Objectives

1. **Duplicate Events Detection & Merge on Data Quality:** Automatically detect duplicate life events for the same person (2+ singleton vitals such as `birth`, `baptism`, `death`, `burial`, `cremation`, plus compatible clustered repeatable events such as `residence` or `occupation`) and couple/union events (`marriage`, `engagement`, `divorce`, `annulment`), propose non-destructive merged payloads highlighting conflicts, and support 1-click merge, customizable field merge, safe batch auto-merge, dismissal (`DUPLICATE_EVENT`), 1-click Undo (`event_merge_bundle`), and MCP tooling.
2. **MCP Duplicate Person Merge & PAT Persistence/Expiration Fixes:** Fixed MCP `merge_duplicate_individuals` no-op behavior caused by JSON-RPC wrapper/alias normalization gaps, ensured Personal Access Tokens (`mcp_pat_...`) persist without exposing `token_hash` over HTTP and survive resets, fixed non-UTC RFC-3339 token expiration evaluation, and aligned omitted PAT scope defaults with the caller's role ceiling.
